Tablero Lista de Tareas

Cómo trabajamos: cada historia de usuario (HU) tiene su propia rama, se prueba en develop y solo lo estable llega a main para entregar.

Las tres ramas

main

Lo que se entrega. Siempre estable.

Nunca se sube código directo. Solo recibe merges desde develop.

develop

Donde se junta y se prueba todo.

Recibe cada HU terminada. Cuando todo funciona, pasa a main.

feature/HU-XX-…

Una rama por cada historia de usuario.

Sale de develop y vuelve a develop al terminar.

Así se mueve el código

Pasos para cada HU

  1. Partir de develop actualizado
    git checkout develop
git pull
  2. Crear la rama de la HU
    git checkout -b feature/HU-01-crear-tarea
  3. Trabajar y hacer commits con el número de la HU
    git commit -m "HU-01: agrega formulario de tarea"
  4. Terminada la HU, unirla a develop y probar
    git checkout develop
git merge feature/HU-01-crear-tarea
  5. Cuando develop está probado, entregar a main
    git checkout main
git merge develop
Regla de oro: nunca se hace commit directo en main. Si estás en main, cambia a develop o a tu rama de HU antes de trabajar.
